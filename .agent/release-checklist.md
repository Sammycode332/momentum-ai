# Release checklist

Unchecked items are gates, not implied completion.

- [ ] Confirm applied migration versions and record hashes/branch/role grants.
- [ ] Verify every private table with two synthetic users at SQL and HTTP layers.
- [ ] Resolve first-load authentication rejection with sanitized Network evidence.
- [ ] Exercise all new workspace workflows against the migrated development DB.
- [ ] Review desktop/tablet/mobile screenshots, themes, keyboard use and contrast.
- [ ] Verify export completion, cancellation and owner isolation in the real app.
- [ ] Complete full account deletion and agree audit/provider/backup retention.
- [ ] Validate Gemini tutoring, interviews and failures with a small approved live sample.
- [ ] Verify Remotive freshness, attribution and unavailable-source behavior live.
- [ ] Activate worker and test quiet hours, rescheduling, retries and device push.
- [ ] Validate installable PWA assets on supported desktop/mobile platforms.
- [ ] Run container images and CI; pin/scan tested dependencies and image versions.
- [ ] Configure HTTPS, private backend network, exact auth origins and secrets.
- [ ] Configure monitoring, support contact and provider cost alerts.
- [ ] Rehearse backup restoration and application rollback in staging.
- [ ] Review privacy/terms drafts and publish approved policies.
- [ ] Review diff and ignored secrets; obtain explicit approval before push/deployment.

Automated checks recorded in progress.md establish only the behavior they cover.
