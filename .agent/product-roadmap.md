# Product Roadmap

## MVP — approximately 10 hours

The MVP is a secure thin vertical slice, constrained to:

- Multi-user authentication.
- Short guided onboarding.
- Personalized dashboards.
- User-specific core records.
- Core AI planning.
- Structured memory proposals and user approval.
- Controlled task reprioritization.
- Core evaluation tests, including safety and tenant isolation.

The delivery sequence is foundation → authentication/RLS → onboarding/core records → dashboard → AI planning/memory → controlled autonomy → evaluations/release checks. Each addition must preserve user isolation and have evidence-based acceptance criteria.

## Stretch / post-MVP

- Background monitoring.
- Automated internship and job discovery.
- GitHub integration.
- Advanced analytics.
- Additional notification channels.

## Scope governance

Do not add an MVP capability without documenting what is deferred, the time/security/cost impact, and any new decision or blocker. Deployment services, scheduling, integrations, and sophisticated automation are not implicitly in scope merely because they may be useful later.
